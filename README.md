# WriteMind AI

**Detect Instantly. Suggest Intelligently. Let Users Decide.**

WriteMind AI is a privacy-first writing assistant: a Chrome extension (Gmail,
WhatsApp Web, LinkedIn and any web text editor) and a Windows desktop app
(Word, Outlook, Notepad, WhatsApp Desktop), sharing one FastAPI intelligence
engine that combines a self-hosted LanguageTool with AI contextual correction.

> Every correction requires your explicit approval. WriteMind never changes
> your text on its own, never logs keystrokes, skips password and sensitive
> fields, and does not store what you write.
